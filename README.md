# screenferry

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> **Status:** Pre-release, API unstable.

A standalone, framework-agnostic, zero-backend TypeScript library for transferring files between devices via animated 2D barcodes (camera ↔ screen). Works fully offline without server infrastructure or peer-to-peer network connections.

## Features (Planned)

- **v1:** Animated QR codes with Luby Transform fountain codes for fault-tolerant visual data transport.
- **Zero-Backend & Offline:** Performs all encoding and decoding entirely in-browser.
- **Framework-Agnostic:** Designed to work with any JavaScript/TypeScript framework or vanilla web apps.
